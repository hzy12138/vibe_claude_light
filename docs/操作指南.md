# Claude Light 操作指南

## 环境要求

- Windows 10/11 x64
- .NET 8 SDK（仅编译需要）
- Visual Studio Code + Claude Code

## 一、编译

### 安装 .NET 8 SDK

```powershell
winget install Microsoft.DotNet.SDK.8
```

验证安装：

```powershell
dotnet --version
# 输出类似: 8.0.421
```

### 编译项目

```powershell
cd ClaudeLight.CSharp
dotnet publish -c Release --self-contained -r win-x64 -o publish/
```

编译成功后 `publish/` 目录下有三个可执行文件：

| 文件 | 用途 |
|------|------|
| `ClaudeLight.exe` | 主程序（红绿灯 + 系统托盘） |
| `ClaudeLight.CLI.exe` | Hook 执行器（被 Claude Code 调用） |
| `ClaudeLight.Clean.exe` | 卸载工具 |

## 二、安装与启动

### 方式 1：手动运行

直接双击 `publish/ClaudeLight.exe`。

启动后会自动：
- 将红绿灯 hook 配置写入 `~/.claude/settings.json`
- 弹出气泡提示"Claude Light 已启动 🚦"
- 在系统托盘显示红绿灯图标
- 开始监听 Claude Code 活动

### 方式 2：开机自启动

右键托盘图标 → 勾选 **开机自启动**，下次开机自动启动。

## 三、运行效果

在 VSCode 中使用 Claude Code 时，红绿灯窗口会出现在屏幕右侧：

| 灯色 | 含义 |
|------|------|
| 🔴 红灯常亮 | Claude Code 正在执行任务 |
| 🔴🟡 红底+黄灯闪烁 | Claude Code 弹出权限确认框，等你操作 |
| 🟢 绿灯常亮 | 任务完成 |
| ⚫ 全灭 | Claude Code 未运行 |

每个 Claude Code 项目会显示独立的红绿灯窗口，窗口上显示项目名和路径。多个窗口自动偏移 30px 不会重叠。

## 四、窗口操作

| 操作 | 效果 |
|------|------|
| **双击窗口** | 切换竖排/横排布局 |
| **拖拽窗口** | 移动位置 |
| **关闭窗口** | 最小化到系统托盘（程序仍在运行） |

## 五、系统托盘

### 左键

点击托盘图标显示气泡提示，列出当前运行中的项目。

### 右键菜单

| 菜单项 | 功能 |
|--------|------|
| **切换布局** | 切换所有窗口的横排/竖排布局 |
| **显示/隐藏全部** | 一键显示或隐藏所有红绿灯窗口 |
| **开机自启动** | 勾选后开机自动启动 |
| **退出** | 完全退出程序 |

## 六、Hook 配置详解

程序启动时会自动修改 `~/.claude/settings.json`，添加以下 hook 配置：

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "*",
      "hooks": [{
        "type": "command",
        "command": "\"ClaudeLight.CLI.exe\" hook running $CLAUDE_PROJECT_DIR"
      }]
    }],
    "PostToolUse": [{
      "matcher": "*",
      "hooks": [{
        "type": "command",
        "command": "\"ClaudeLight.CLI.exe\" hook done $CLAUDE_PROJECT_DIR"
      }]
    }],
    "PermissionRequest": [{
      "hooks": [{
        "type": "command",
        "command": "\"ClaudeLight.CLI.exe\" hook confirm $CLAUDE_PROJECT_DIR"
      }]
    }],
    "Stop": [{
      "hooks": [{
        "type": "command",
        "command": "\"ClaudeLight.CLI.exe\" hook idle $CLAUDE_PROJECT_DIR"
      }]
    }]
  }
}
```

### 四个 Hook 的工作原理

```
Claude Code 开始执行工具
  → PreToolUse 触发
    → CLI hook running → JSON: status="running"
      → 🔴 红灯

Claude Code 工具执行完成（会话继续）
  → PostToolUse 触发
    → CLI hook done → JSON: status="running"
      → 🔴 红灯（保持！不等 Stop 不会绿）

Claude Code 弹出权限确认框
  → PermissionRequest 触发
    → CLI hook confirm → JSON: status="confirm"
      → 🔴🟡 红底+黄闪

Claude Code 完成整个回复
  → Stop 触发
    → CLI hook idle → JSON: status="idle"
      → 等待 3 秒无新事件 → 🟢 绿灯
```

> **设计理由**: PostToolUse 在每次工具完成后都触发，但一次 Claude Code 回复会连续调用多个工具。用 Stop 而不是 PostToolUse 判断"完成"，可以避免工具间思考时误亮绿灯。

### 状态文件位置

Hook 被触发后，CLI 工具会在 `~/.claude-lights/` 目录下创建 JSON 文件。

```
~/.claude-lights/
  E__workplace_vibe_claude_light.json
  c__Users_xxx_Desktop_my-project.json
```

## 七、与其他 Hook 共存

如果你已经有其他 hook 配置（比如 dashboard 事件日志），红绿灯的 hooks 会和它们合并共存，不会覆盖已有的配置。

## 八、调试

### 查看状态文件

```powershell
ls ~/.claude-lights/
cat ~/.claude-lights/<项目名>.json
```

### 查看程序日志

```powershell
cat <ClaudeLight.exe所在目录>\claude-light.log
```

### 手动触发 CLI 测试

```powershell
ClaudeLight.CLI.exe hook running "C:\path\to\project"
ClaudeLight.CLI.exe hook confirm "C:\path\to\project"
ClaudeLight.CLI.exe hook done "C:\path\to\project"
ClaudeLight.CLI.exe hook idle "C:\path\to\project"
```

## 九、卸载

```powershell
ClaudeLight.Clean.exe --force
```

会清除：
- `~/.claude/settings.json` 中的红绿灯 hook 配置
- `~/.claude-lights/` 状态文件目录
